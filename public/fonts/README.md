# Self-hosted fonts

Latin WOFF2 subsets downloaded from the Google Fonts CSS API on 17 October 2026:
Inter (400–700 request), JetBrains Mono (400–700 request), and Space Grotesk
(400–700 request). The API supplies the same variable file for these weights.
All families use font-display: swap; only above-the-fold sans/display fonts are
preloaded. Unsupported glyphs use the existing system fallbacks.

Fonts are distributed under the SIL Open Font License. The original license
and copyright notices are included alongside the font files:
inter-OFL.txt, jetbrainsmono-OFL.txt, and spacegrotesk-OFL.txt.

Sources: https://fonts.google.com/ and https://github.com/google/fonts/tree/main/ofl
